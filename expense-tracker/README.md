# Ledgerly: Personal Expense Tracker

A responsive React app to record income and expenses, categorize spending and see the remaining balance.

## Features
- Add, edit and delete transactions (income or expense)
- Form validation with clear error messages
- Search by title, filter by type and category
- Live balance, income and expense totals
- Reports page: spending by category and share of income used
- Data saved in the browser (localStorage)
- Three views with React Router: Dashboard, Transactions, Reports

## Tech
React 18, Vite, React Router, HTML5, CSS3, JavaScript ES6 (useState, useEffect, useMemo, Context API)

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
